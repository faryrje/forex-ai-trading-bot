# Forex AI Trading Bot

AI powered Forex trading framework.

## Features

- Paper trading mode
- Risk management
- Technical indicators (EMA/RSI)
- AI signal engine
- Backtesting foundation
- MT5 connector foundation
- Order management
- Stop loss and take profit calculation

## Installation

```bash
pip install -r requirements.txt
```

## Run

```bash
python main.py
```

## Safety

Live trading requires validation, backtesting and broker testing before real funds are used.
